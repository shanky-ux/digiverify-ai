# DigiVerify AI - Startup Guide

This project has been updated to use a **SQLite backend** by default, allowing you to run it without needing a MySQL server installed.

## 🚀 How to Run Locally

### 1. Start the Backend
Navigate to the `backend` folder and run:
```powershell
python app_sqlite.py
```
*   **API URL:** `http://localhost:5000`
*   **Credentials:**
    *   **Citizen:** Aadhaar: `123456789012` | Email: `test.user@gmail.com`
    *   **Admin:** Username: `admin` | Password: `admin123`

### 2. Start the Frontend
Navigate to the `ReactFrontend/fund_tracker` folder and run:
```powershell
npm install   # If running for the first time
npm run dev
```
*   **URL:** `http://localhost:5173`
